Sukoon bundled Quran fonts
===========================

All font binaries in this directory are unmodified copies of the original
font files named below. The SHA-256 values make the exact bytes auditable.
The app registers them for the current process only; it does not install them
in the user's system font collection. The seven text-font families listed by
quranfonts.com include two families whose source terms do not permit
redistribution; those two are intentionally not bundled (see the final
section).

Format and compatibility
------------------------

The bundled files are the original TrueType or OpenType font files. They
contain Unicode Arabic cmap entries and OpenType Arabic shaping tables; they
are text fonts, not page-index/private-glyph mushaf fonts. Apple documents
CTFontManagerRegisterFontsForURL as the CoreText registration API
(https://developer.apple.com/documentation/coretext/ctfontmanagerregisterfontsforurl(_:_:_:))
and CTFontManagerIsSupportedFont as the native-format check.
QuranFonts performs that check before every process-scoped registration and
reports unsupported formats in registrationErrors rather than silently
substituting another font. No WOFF/WOFF2 web-only file is shipped.

Families not bundled: concrete source-term blockers
----------------------------------------------------

* Indopak Nastaleeq (quranfonts.com) currently downloads
  AlQuran-IndoPak-by-QuranWBW. Its embedded name-table notice states:
  "NOT FOR SALE, NOT FOR MODIFICATION, NOT FOR DISTRIBUTION OR NOT FOR
  DEVELOPMENT WITHOUT WRITTEN NOTICE BY QURANWBW.COM" and supplies
  quranwbw@gmail.com. The quranfonts page's free-download wording does not
  override that explicit restriction. Written redistribution permission was
  not available, so this binary is not copied or offered as an option.

* Me Quran currently embeds: "Typeface and data © 2005, Meor Ridzuan. Free
  for non commercial use. Other use, contact meory@yahoo.com". Sukoon's
  redistribution/commercial status is not granted by that notice, and no
  written permission for bundling was available. This binary is not copied
  or offered as an option.

The excluded binaries were inspected as Unicode Arabic text fonts, but are
not silently replaced with page/glyph fonts or fake options. They can be
added only after the respective copyright holders grant redistribution terms
covering this app.
